# 🐍Python do básico ao avançado

Repositório criado para armazenar exercícios, projetos e estudos desenvolvidos durante minha jornada de aprendizado em Python.

## 📂 Estrutura do Projeto

### 🟢 Básico
Projetos voltados para a aprendizagem dos conceitos fundamentais da linguagem.


### 🟡 Intermediário
Projetos que utilizam estruturas de dados, orientação a objetos e bibliotecas externas.


### 🔴 Avançado
Projetos com manipulação de dados, visualização e automação.


## 🛠️ Tecnologias Utilizadas

- Python 
- Pandas
- Matplotlib
- Requests
- BeautifulSoup

## 🎯 Objetivo

Praticar programação em Python através da criação de projetos progressivos, evoluindo dos conceitos básicos até aplicações mais avançadas.
